# Legacy dark

`legacy-dark` preserves the former dark, glowing, card-heavy treatment as an
explicit opt-in compatibility profile. It is not the default. Do not select it
from a vague request for a visual; choose it only when the user asks for this
legacy appearance or a dark visual explicitly.

When selected, retain the existing local-only delivery contract. Do not copy
the Editorial V1 tokens into this profile merely to create a mixed treatment.
